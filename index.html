Quadratic Relationships

From real-life curves to graphs and equations — a guided tour.

1 · Real life 2 · Function & tests 3 · Parabola features 4 · Two forms 5 · Sketching

Today we answer one big question: what is a quadratic, how do we spot it, and how do we draw it? A quadratic relationship appears whenever one quantity depends on the square of another — like the height of a thrown ball, the area of a square, or the shape of a satellite dish. Day 1

Where do quadratics appear in real life?

🏀 Throwing a ball

Up, peak, down: a curved path.

⬛ Area of a square

A = s²

s = 1,2,3,4,5 → A = 1,4,9,16,25

🌱 Garden

x(x+5) = x² + 5x

Width x, length x + 5.

✔ U-shape or upside-down U ✔ Has a max or min value ✔ One quantity depends on the square of another

A situation is quadratic when something is squared. A thrown ball rises, reaches a highest point, then falls — that curve is a parabola. Fireworks, fountains and basketball shots do the same. A weekly allowance (+₱100 each week) or ₱50 per kilo is linear, a straight line, so those are not quadratic. Key idea: if doubling the input more than doubles the output (because of the square), you’re likely dealing with a quadratic.

Day 2

The quadratic function

f(x) = ax² + bx + c
ax² = quadratic term (a ≠ 0) bx = linear term c = constant

Is f(x) = 2x² + x + 1 quadratic?

Yes. a = 2, b = 1, c = 1, and a ≠ 0.

Is h(x) = (x + 6)² quadratic?

Expand: x² + 12x + 36. So a = 1, b = 12, c = 36. Yes!

Is g(x) = 3x + 2 quadratic?

No — the highest power is x¹, so it’s linear.

Is k(x) = −x² + 4x quadratic?

Yes. a = −1, b = 4, c = 0. Note that a can be negative.

“Quad” means square. The only rule: the biggest power of x is 2, so a can’t be zero (otherwise x² disappears and it becomes a line). If it’s not in the form ax² + bx + c yet, expand and simplify first, like (x + 6)². Watch out: b or c can be zero — that’s still quadratic. But if a = 0, it’s not.

Subtract each y from the next one. If those answers are already equal, it’s a straight line (linear). If they’re not equal, subtract again. When the second differences are equal, you have a quadratic. Try it yourself: 7, 16, 31, 52, 79, 112 gives second differences of 6 — quadratic! The constant second difference tells you that a = (second difference)/2.

Reading a parabola: y = (x + 2)² − 1

Concavityup

💡 vertex form: y = a(x − h)² + k → vertex (h, k) 📐 axis: x = h ↕️ opens up if a > 0, down if a < 0

If a > 0 the parabola opens up and has a lowest point; if a < 0 it opens down with a highest point. That turning point is the vertex. In y = a(x − h)² + k the vertex is (h, k), the axis is x = h, and k is the min or max. The domain is always all real numbers; the range depends on the opening direction. Quick check: for y = (x + 2)² − 1, a = 1 > 0 so it opens up, and the lowest point is (−2, −1).

Day 5

Two forms, one function

Vertex form

y = a(x − h)² + k

General form

y = ax² + bx + c

Vertex → General: y = 3(x − 2)² + 4

y = 3(x − 2)² + 4
y = 3(x² − 4x + 4) + 4expand (x − 2)²
y = 3x² − 12x + 12 + 4multiply by 3
y = 3x² − 12x + 16simplify

General → Vertex (extra example)

y = x² − 8x + 12 → y = (x² − 8x + 16) − 16 + 12 → y = (x − 4)² − 4. Vertex (4, −4).

y = 2x² + 12x + 10 → 2(x² + 6x) + 10 → 2(x² + 6x + 9) − 18 + 10 → y = 2(x + 3)² − 8. Vertex (−3, −8).

Going from vertex form to general form: expand the squared bracket, multiply by a, then add the number at the end. Going back, factor — when the trinomial is a perfect square, it becomes (x − h)². Tap the button to reveal each step one at a time. Remember: the vertex form immediately gives you the turning point; the general form is handy for spotting the y-intercept (0, c).

Day 6

Sketching f(x) = x² − 6x + 7

1. choose x (negative, zero, positive) 2. substitute → y 3. complete the table 4. plot points 5. draw a smooth curve

Five steps: pick x-values (negative, zero, positive), substitute them into the equation to get y, complete the table, plot the points, then connect them with one smooth curve — not straight segments. The lowest point (3, −2) is the vertex, and it matches the table. Extra tip: the axis of symmetry is x = 3, and the y-intercept is (0, 7).
